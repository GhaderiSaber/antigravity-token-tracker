# EGM Documentation & Codebase Drift Report (2026-11-25)

This report audits all 11 modified EGM contract documents (`README.md`, `src/README.md`, and `src/*/README.md`) against the current source code on disk for both doc-to-code mismatches and missing code coverage.

## README.md
- Claims `agy-token watch` (`README.md:41, 122-125`), `agy-token remove` (`README.md:177-179`), and `agy-token switch` (`README.md:183-200, 312`) as working CLI commands, but none of them are registered in `cli_command()` or handled in `dispatch()` (`src/main.rs:68-162`); invoking them exits with code `1`.
- Claims flags `agy-token status --models` (`README.md:118`), `agy-token daemon --threshold` / `--cooldown` (`README.md:20, 144`), and `agy-token doctor --fix` / `--no-network` (`README.md:217-221`), but `src/main.rs` (`run_status_ip`, `run_daemon_doctor`) ignores all of them; additionally `tracker_lib::daemon::run_daemon` (`src/daemon/daemon.rs:93-104`) ignores `_auto_switch` and hardcodes `threshold = 1.0`, `cooldown_seconds = 120.0`, and `restart = true` in `run_daemon_step`.
- Claims a desktop notification pops up "the moment your weekly tokens refresh back to 100%" (`README.md:24`), whereas `send_desktop_notification` is only called during failover (`src/daemon/failover.rs`) and tray menu actions (`src/tray/applet.rs`).
- Claims `systemctl --user enable --now antigravity-token-tracker.service` enables auto-failover alongside the tray (`README.md:147-150`), whereas `install.sh:41` configures the service with `ExecStart=$TARGET_BIN tray --interval 60` and `run_tray` (`src/tray/mod.rs:88-147`) never invokes `evaluate_and_execute_failover`, `evaluate_and_execute_balancer`, or `record_token_history_snapshot`, nor populates `TrayState::backup_candidate`.
- Claims Geo-Shield terminates processes "within < 50ms" on VPN drop and provides a "Relaunch Guard" that "Blocks Antigravity from connecting until a safe VPN egress is re-established" (`README.md:34-35`), whereas `run_daemon` and `run_tray` only check Geo-Shield on their polling tick (default 60s), `get_ip_geo(false)` caches results for 60s (`src/shield/geo.rs:CACHE_TTL_SECS`), `kill_antigravity_processes` waits up to 1.5s (`15 * 100ms`) between `SIGTERM` and `SIGKILL` (`src/shield/shield.rs:140-155`), and no code in `src/shield/shield.rs` or `src/balancer/switcher.rs:launch_antigravity` blocks launches or connections (`ShieldConfig::auto_relaunch` is unused).
- `Local Interface & Invariants` for `install.sh` (`README.md:328`) omits that `install.sh` also activates `antigravity-token-tracker.service` (or falls back to `nohup "$TARGET_BIN" tray`), symlinks `/usr/local/bin/agy-token` when `/usr/local/bin` is writable, and prints GNOME AppIndicator extension instructions when missing (`install.sh:66-130`).
- `Global Invariants` (`README.md:337`) claims "All 9 backend domain models statically satisfy `Send + Sync` at compile time `[src/lib.rs]`", whereas `src/lib.rs:30-49` only asserts 17 specific types across 6 modules (`auth`, `balancer`, `shield`, `storage`, `quota`, `daemon`) and omits `cli`, `tray`, and `web`.
- `Global Side Effects` (`README.md:345`) cites `googleapis.com/oauth2/v3/userinfo`, whereas `USERINFO_URL` in `src/auth/oauth.rs:40` is `https://www.googleapis.com/oauth2/v3/userinfo`.

## src/README.md

- `Invariants` omits command-level routing and handler invariants in `src/main.rs`: `cli_command()`/`dispatch()` (`src/main.rs:68-162`) only implement 12 of the 17 commands listed in `print_root_help()` (omitting `watch`, `snapshot`/`save`, `remove`, `switch`, `burn`, `test-notify`/`notify-test`/`test-toast`); `run_daemon_doctor` defaults `daemon` `--interval` to `60`s (`src/main.rs:829`) vs `300` in `print_daemon_help()`; `run_balance` (`src/main.rs:690-749`) exits with code `1` on invalid `--strategy`/`strategy` and ignores `rotate`, `config`, `--spread`, `--interval`, `--expiry-window`, `--min-quota`, `--dry-run`, `--force`; `run_shield` (`src/main.rs:293-469`) ignores `--mode`, `--allow`, `--action` flags and only reads positional `extra_args`; `run_pace_check` (`src/main.rs:645-653`) for `pace` only fetches quotas without computing/printing burn rates; and `run_list`, `run_sync`, `run_web`, and `run_tray` return `ExitCode::FAILURE` / `ExitCode::from(1)` on I/O, sync, server, or tray errors.
- `Side Effects` (`src/README.md:42`) attributes "Performs external network HTTP queries to fetch egress IP geolocation and quota snapshots" to `[src/main.rs:run_shield]`, whereas `run_shield` only fetches egress IP geolocation (`get_ip_geo`); quota snapshots are fetched in `run_pace_check`, `run_status_ip`, `run_daemon_doctor` (`daemon`), `run_tray`, and `run_web`.
- `Side Effects` omits side effects of the remaining `src/main.rs` handlers: `run_balance` reading/writing `balancer.json`; `run_list` reading `accounts.json`; `run_status_ip` and `run_pace_check` syncing Antigravity sessions and fetching quotas/IP geo; and `run_daemon_doctor` running `run_doctor_suite()` (D-Bus, HTTPS `HEAD` probes, process discovery) and `run_daemon()` (Geo-Shield enforcement, sync, quota fetch, `token_history.jsonl` append, balancer/failover execution, and desktop notifications).
